函数指针、递归、可变参数与 Lambda

函数指针保存普通函数入口，Lambda 生成可携带状态的闭包对象，递归则让函数通过调用栈重复处理子问题。C 风格省略号参数丢失类型信息，现代接口更适合使用模板参数包或明确的范围类型。

函数指针

函数指针保存与特定签名匹配的函数地址，可用于回调和策略选择。

捕获 lambda 不能转换为普通函数指针；泛型接口通常使用函数模板或 std::function。

函数指针保存具有特定签名的函数地址，可为空并可作为回调传递。重载函数取地址时需要由目标类型消除歧义。无捕获 lambda 能转换为兼容函数指针；需要保存状态的可调用对象则用模板参数或 std::function 等包装。

函数指针实现策略选择

函数指针签名必须匹配；捕获 lambda 需要模板、std::function 或其他类型擦除接口。

递归

递归函数通过更小子问题调用自身，并必须具有可到达的终止条件。

递归深度受实现资源限制；深线性递归在 C++ 中不能依赖尾调用优化，应考虑迭代写法。

递归函数必须有让问题规模趋向终止条件的路径，每层调用还会保存参数和局部状态。深度不受输入约束时可能耗尽调用栈。尾递归优化不是 C++ 保证，能够自然改写为循环或显式容器时可以控制资源上限。

递归和终止条件

每次调用缩小 value 并最终到达终止条件；深递归和乘法溢出仍需单独限制。

省略号参数及其风险

C 风格省略号不会保留参数数量和完整类型信息，并受默认实参提升规则影响。

现代 C++ 使用可变参数模板、span、initializer_list 或格式化库表达可检查接口。

C 风格省略号不会携带实参数量和类型，默认实参提升后只能依靠额外协议手工还原；协议一旦不一致就可能越界读取或用错误类型解释数据。可变参数模板、折叠表达式以及类型安全的格式化接口能够在编译期保留这些信息。

用可变参数模板替代 C 省略号

可变参数模板保留每个实参的类型，折叠表达式自 C++17 起可用；C 风格省略号缺少数量和类型信息。

使用可变参数模板保留类型信息

每个实参类型在实例化时可见，避免 C 风格省略号的手工协议。

C 风格省略号仍在语言中，但现代 C++ 通常以可变参数模板保留类型信息。

Lambda 表达式

lambda 产生匿名闭包对象，参数列表和函数体定义调用行为。

无捕获 lambda 可转换为函数指针；泛型 lambda 的 auto 参数自 C++14 可用。

lambda 表达式产生一个匿名闭包类型，对象中保存按值捕获的状态，调用运算符实现函数体。无捕获 lambda 可以转换为兼容的函数指针；带捕获 lambda 需要以具体闭包类型、模板参数或 std::function 等类型擦除包装保存。

lambda 作为算法谓词

lambda 产生匿名闭包对象，适合把局部策略直接传给算法。

将筛选条件交给标准算法

Lambda 只捕获判断所需的最小状态，算法负责遍历范围。

捕获列表只保留回调所需状态；回调若会被保存，必须重新检查每个引用捕获和 this 的生命周期。

Lambda 捕获

捕获列表决定闭包保存外部变量的副本或引用，默认捕获会隐藏实际依赖。

引用捕获不能超过目标生命周期；异步回调应明确捕获值、所有权或 weak_ptr。

按引用捕获只保存访问关系，不延长局部对象生命周期。回调被异步执行或存入容器时，按值捕获所需状态通常更容易审查；捕获 this 也只复制指针，不能保证当前对象在回调执行时仍存在。

显式捕获回调依赖

minimum 按值进入闭包，回调离开当前作用域后仍可使用副本；引用捕获需要额外保证来源生命周期。

异步保存时按值捕获所需状态

闭包拥有移动后的字符串，不依赖创建作用域中的局部对象继续存活。

异步或延迟执行优先让闭包拥有所需值；共享可变状态还需要同步策略，按值捕获本身并不解决并发访问。
