Linux 文件检索、重定向与文本处理

Linux 命令行工具通常通过标准输入读取字节流，并把结果写入标准输出。文件检索、重定向和文本处理可以由此组合成一条流水线。

查找命令与文件

type 和 command -V 用于确认 Shell 会执行哪个命令；find 遍历实时目录树；locate 查询预先建立的路径数据库。

find 的测试条件默认通过逻辑与连接。涉及删除或执行时，可以先只打印匹配项，再增加 -delete 或 -exec。locate 速度快，但数据库可能尚未包含刚创建的文件，也可能受权限过滤和更新周期影响。

标准流与文件描述符

进程启动时通常拥有三个文件描述符：

编号 名称 默认连接
0 stdin 终端输入
1 stdout 终端输出
2 stderr 终端错误输出

重定向按从左到右的顺序建立。>all.txt 2>&1 让两个流写入同一文件；2>&1 >all.txt 则让标准错误继续指向重定向前的标准输出。

管道与 tee

管道只连接左侧标准输出和右侧标准输入，标准错误不会自动进入管道。许多命令可以直接接收文件参数，因此 grep pattern file 比 cat file | grep pattern 少启动一个进程；当 cat 负责合并多个文件或提供特殊输入时，管道写法仍有用途。

常用文本工具

工具 作用
less 分页查看文本，退出后是否保留屏幕取决于终端和参数
head / tail 读取开头或末尾，默认 10 行
sort 按指定规则排序行
cut 按字符位置或分隔字段选取内容
tr 转换或删除单字节字符集合

awk 按记录和字段处理文本
sed 按地址和规则编辑流

基本与扩展正则表达式

grep 默认使用基本正则表达式，grep -E 使用扩展正则表达式。是否需要转义圆括号、花括号和 | 取决于所选模式。

grep -F 把模式作为固定字符串处理。. 匹配任意单个字符，.* 表示任意长度字符序列，并不是逻辑与运算符。

文本工具按行和字节处理时会受到 locale、编码、空字符和换行规则影响。处理任意文件名时不能依赖换行分隔，应使用 find -print0 与支持 -0 的下游工具。
